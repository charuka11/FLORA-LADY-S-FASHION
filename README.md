
# FLORA LADY'S FASHION 

Welcome to **Flora Lady's Fashion**, a simple and elegant personal e-commerce website project. This project was created to provide an enjoyable shopping experience for fashion, beauty, jewellery, and accessories.

## ✨ Features

* **Product Catalog:** Browse a wide variety of products across different categories.
* **Category Filtering:** Easily filter products by Fashion, Jewellery, Beauty & Cosmetics, and Accessories.
* **Search Functionality:** Quickly search for your favorite items using the search bar.
* **Shopping Cart:** Add products to the cart, adjust quantities, remove items, and see the total price update in real-time.
* **Local Storage:** Your cart items are saved in the browser, so they won't disappear if you refresh the page.

## 🛠️ Technologies Used

* **HTML5:** For the structure of the web pages.
* **CSS3:** For styling, layout, and responsive design.
* **JavaScript (Vanilla):** For all the interactive features, including the cart system, search, and filtering.
